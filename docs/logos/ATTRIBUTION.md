# Format logo attribution

The SVG marks in this folder identify the applications whose file formats
PreviewGen reads. They are used nominatively — to show which software authored
a supported format — and do not imply sponsorship or endorsement by any of
these vendors.

## Notes

- `procreate.svg` is the standalone Procreate "P" mark extracted from the
  Procreate Folio wordmark, because no freely licensed standalone Procreate
  icon exists.
- `autodesk-maya.svg` is the Devicon "Maya" mark; Autodesk's own brand assets
  are not redistributed here.
- Marks sourced from Iconify and Simple Icons use `fill="currentColor"`, which
  renders in the reader's text colour. On GitHub's light and dark README
  themes this stays legible without any inline styling.
